# PCA Image Compression and Reconstruction

Este projeto demonstra a aplicação de **PCA (Análise de Componentes Principais)** para compressão e reconstrução de imagens em escala de cinza, avaliando a qualidade das reconstruções usando métricas como **MSE (Erro Quadrático Médio)**, **PSNR (Relação Sinal-Ruído de Pico)** e o **tamanho em MB** das imagens reconstruídas.
